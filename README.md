## Descripción
Ecualizador de 3 bandas (graves, medios y agudos) con filtros biquad en Python,
con ganancia ajustable de −12 a +12 dB por banda, aplicado a audio real.

## Estructura
- src/    código en Python
- audio/  grabaciones de prueba
- docs/   propuesta y figuras

## Dependencias
Python 3, NumPy, SciPy, Matplotlib
